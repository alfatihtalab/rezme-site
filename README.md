# Rezme website

Static pages served by GitHub Pages at https://apprezme.com:

| URL | File |
| --- | --- |
| / | index.html |
| /privacy/ | privacy/index.html |
| /terms/ | terms/index.html |
| /support/ | support/index.html |
| /delete-account/ | delete-account/index.html |
| /changelog/ | changelog/index.html |

The app, App Store Connect and Play Console link to these URLs, so keep the paths.
Edit the HTML directly; styles are in `assets/site.css`. Pushing to `main` publishes in about a minute.
When the privacy policy or terms change, update their "Last updated" date.
